Make a portfolio that feels like you.

Create your page or update one you already made. We’ll guide you through each step.

You’ll need a GitHub account. We’ll walk you through creating a repository and a short-lived access token.

Connect your repository

1
Create your repository

A repository is the folder where your website lives. Name it portfolio or me.

Show me how

Open GitHub’s new repository page. Give it a name. For a new portfolio, leave it empty (a README is okay), then choose Create repository. Your website will be public when published.

2
Make a temporary access token

This is a one-day key that lets this page save files to your repository.

Show me the safe settings
  1. Open Fine-grained tokens and choose Generate new token.
  2. Set expiration to 1 day and choose only the repository from step 1.
  3. Allow Contents: read and write. Leave all other permissions off.
  4. Create the token and copy it. Anyone with this key can change files in that repository; never share it.
Enter the owner and repository name, not the full web address.
Only used in this page. Refreshing clears it.

GitHub asks you to choose Metadata: read-only automatically. We check that the token can write to this repository, but GitHub does not tell this page the token’s expiry, repository limit, or all its permissions. If you gave it extra access, delete it in GitHub and make a new one.

About your website: This editor does not need Pages access. After saving, we’ll show you three simple clicks to publish your site.

Before we connect

A personal access token is a temporary key. It lets this page save your portfolio to the one repository you choose. This page forgets the key when refreshed.

Keep it safe: Fine-grained token · expires in 1 day · one repository · Contents read/write only.
What am I agreeing to?

GitHub’s API does not let this page verify token expiry or permissions. Do not use a shared computer, never share the token, and delete it in GitHub if you gave it more access than listed. By continuing, you agree to follow GitHub’s Terms of Service and Community Code of Conduct.
